# Limitations and responsible use

- Hosted Gemini APIs can change over time, even under a fixed model name.
- Corpus construction depends on publisher availability and PDF extraction
  quality; scans, dense tables, and nonstandard typography remain difficult.
- Exact evaluation depends on identity, not semantic similarity alone. Correct
  facts can miss if a paper ID, locator type, page, object ID, row key, or cell
  assignment is wrong.
- The source-object indexes require several gigabytes and corpus-scale
  preprocessing.
- The public repository intentionally omits benchmark inputs, PDFs, generated
  predictions, private run artifacts, and credentials.
- The historical 0.792252 adaptive artifact is not the selected reproducible
  system and is not included here.
- LitTraceQA annotations are non-commercially licensed; source PDFs retain
  their publishers' terms.
- TRACE should not be used for high-stakes decisions without independently
  checking the cited paper and answer.
